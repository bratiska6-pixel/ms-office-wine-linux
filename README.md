> **Готовое решение «из коробки»** для автоматического развертывания, настройки и бесшовной интеграции **Microsoft Office 2010 (Word, Excel, PowerPoint)** в дистрибутивах Linux (Ubuntu 24.04/22.04 LTS, Debian 12, Linux Mint, elementary OS).  
> Скрипт автоматически устраняет известные проблемы совместимости: критическую ошибку MSI `1603 (ArpWrite)`, падения инсталлятора от состояния гонки потоков (*race condition*) на многоядерных процессорах, настраивает переопределения библиотек и создаёт нативные ярлыки на Рабочем столе и в меню приложений.

---

## 🎯 Основные возможности

* **Установка «в 1 клик» (`install.sh`):** скрипт самостоятельно проверяет окружение, включает 32-битную архитектуру, доставляет нужные системные пакеты (`wine32`, `winbind`, `cabextract`) и настраивает изолированный префикс.
* **Изолированный префикс (`~/.wine-office`):** 32-битное окружение Windows 7 не конфликтует с системным префиксом `~/.wine` и другими приложениями.
* **Автоматическое устранение багов инсталлятора:**
  * **Обход ошибки 1603 (`ArpWrite` / WineHQ Bug 45208):** автоматическая модификация `config.xml` (`SETUPEXE_DOARPWRITE=0`), предотвращающая аварийный откат установки при записи в реестр апплета удаления.
  * **Защита от сбоя на современных CPU:** запуск инсталлятора с жесткой привязкой к одному ядру (`taskset -c 0`) и пониженным приоритетом (`nice -n 19`), что устраняет состояние гонки потоков MSI-установщика.
* **Полный комплект базовых шрифтов:** автоматическая подгрузка Microsoft Core Fonts (Arial, Times New Roman, Calibri, Verdana) через `winetricks`.
* **Твик `NoReReg`:** предотвращение постоянного повторного запуска окна «Установка компонентов» при каждом старте Word и Excel.
* **Нативная интеграция в ОС:** готовые исполняемые скрипты запуска и `.desktop`-ярлыки для запуска с Рабочего стола и поиска в системном меню приложений.

## 🚀 Быстрый старт (Установка за 3 шага)

### Шаг 1. Клонирование репозитория
```bash
git clone https://github.com/bratiska6-pixel/ms-office-wine-linux.git
cd ms-office-wine-linux
```

### Шаг 2. Подготовка дистрибутива Office 2010
Поместите распакованную папку дистрибутива в `~/Загрузки` или `~/Downloads` (либо положите папку `x86` с файлом `setup.exe` прямо в каталог с репозиторием).

### Шаг 3. Запуск инсталлятора
```bash
chmod +x install.sh
./install.sh
```

1. Скрипт проверит зависимости и настроит изолированное 32-битное окружение Wine.
2. На экране откроется графическое окно мастера установки Microsoft Office.
3. Нажмите кнопку **«Установить»** (или «Настройка», если хотите отключить лишние модули).
4. Дождитесь заполнения зеленой шкалы прогресса (2–4 минуты) и нажмите **«Закрыть»**.
5. На вашем Рабочем столе и в меню приложений появятся готовые ярлыки Word, Excel и PowerPoint!

## ❓ Часто задаваемые вопросы (FAQ) и решение проблем

### 1. Окно «Настройка компонентов» открывается при каждом запуске программы
Дистрибутив **Professional Plus** использует службу корпоративного лицензирования (KMS / OSPP). Скрипт автоматически прописывает параметр `NoReReg` в реестре Wine:
```bash
export WINEPREFIX="$HOME/.wine-office"
wine reg add "HKEY_CURRENT_USER\Software\Microsoft\Office\14.0\Word\Options" /v "NoReReg" /t REG_DWORD /d 1 /f
wine reg add "HKEY_CURRENT_USER\Software\Microsoft\Office\14.0\Excel\Options" /v "NoReReg" /t REG_DWORD /d 1 /f
```
*(Для повседневной работы дома также отлично подходят розничные редакции Home and Student или Standard, не требующие связи с сервером KMS).*

### 2. Ошибка инсталлятора 1603 при ручной установке без скрипта
Это ошибка апплета записи в список установленных программ (`ArpWrite`). В скрипте `install.sh` она решена добавлением параметра в конфигурационный файл:
```xml
<Configuration Product="ProPlus">
	<Setting Id="SETUPEXE_DOARPWRITE" Value="0" />
	<Setting Id="SETUP_REBOOT" Value="Never" />
</Configuration>
```

## 🗑 Полное удаление

Если вам потребуется удалить Microsoft Office и все созданные файлы, запустите скрипт чистого удаления:
```bash
./uninstall.sh
```
Скрипт корректно остановит все активные процессы Wine, удалит префикс `~/.wine-office`, скрипты запуска и ярлыки с Рабочего стола.
